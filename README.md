Uma Pokédex desenvolvida como atividade de revisão, consumindo a PokéAPI para listar e exibir informações dos Pokémons.

## Objetivo

Este projeto foi criado para praticar consumo de API's REST, componentização e gerenciamento de estado no React, através da construção de uma Pokédex funcional.

## Funcionalidades

- Listagem de Pokémons
- Busca por Pokémon
- Visualização de detalhes (tipos, atributos e imagem)
- Interface responsiva

## Tecnologias Utilizadas

- React
- JavaScript
- Vite
- PokéAPI
- CSS

## Como executar

```bash
git clone https://github.com/carloshenrique54/Pokedex.git
cd Pokedex
npm install
npm run dev
```
